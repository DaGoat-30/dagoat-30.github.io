# Stephen Curry Ultimate Fan Hub 🏀🔥

A full-featured Stephen Curry fan website built by **Da Goat**.  
This site brings together everything a real Curry fan needs — news, highlights, stats, wallpapers, interactive tools, and more.

## 🚀 Features

### 🟡 Live Curry Updates
- Auto-refreshing news every 5 seconds  
- Randomized Curry training, charity, and team updates  

### 🟡 Highlights Section
- Recent game moments  
- Warm-up clips  
- Handles, passes, and deep threes  

### 🟡 Season Stats (Editable)
- Points per game  
- Assists  
- 3PT percentage  
- Games played  

### 🟡 Gallery
- High-quality Curry photos  
- Easy to replace with your own images  

### 🟡 Curry Fan Quiz
- 3-question quiz  
- Button reveals answers  

### 🟡 Career Timeline
- Major milestones from 2009 → 2022  
- Finals MVP, MVP seasons, championships  

### 🟡 3PT Tracker
- Add threes  
- Reset counter  
- Tracks your own game stats  

### 🟡 Wallpapers
- Curry wallpapers ready to download  
- Right-click → Save image  

### 🟡 Fan Leaderboard
- Add your name  
- Add your Curry fan level (1–100)  
- Builds a list of fans  

### 🟡 Light/Dark Mode
- Toggle button  
- Smooth transitions  

### 🟡 Extras
- Ideas for future upgrades  
- Playlist embeds  
- Polls  
- Game logs
